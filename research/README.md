# Research & design (not code)

Nothing in this folder runs. It explains **what the game is** and **why decisions were made**.

| File | What it is |
|---|---|
| `GAME_SPEC.md` | The cleaned-up design from the chat log, plus the task list used to build `framework/`. Some numbers were corrected later - see the note at its top. |
| `chat-log.txt` | The original conversation that built the game in Studio. Raw and messy; some designs in it were later replaced. Where it disagrees with the spec, the spec wins. |
| `known-gaps.md` | Decisions made, unfinished work, and what has not been verified. |
| `tooling-notes.md` | How to work on Roblox projects without Studio, and which tools are safe long-term. |
